# 白平衡 White Balance（待審概念頁）

本頁尚未寫入正式 Wiki，也未供簡報使用。主張 ID 對應[驗證表](claims-reviewed.md)。

## 給新手的核心觀念

白平衡是修正不自然色偏的過程（WB-01）。先分清楚兩個對象：光源色溫越高，光色越偏冷；對同一張偏冷的照片，提高相機 WB 的 Kelvin 設定可讓結果較暖（WB-02）。綠—洋紅偏移處理另一個校正方向，不能只靠一個色溫數字處理所有光源（WB-03）。

RAW 容許拍攝後調整 WB，但不代表能補救所有拍攝問題（WB-06）。若用中性參考物取得設定，批次套用之前必須確認照明相同（WB-07）。看起來灰白的日用品不保證色彩中性（WB-08、09），雜訊較高時也應避免只採單一像素（WB-10）。

畫面大量同色主體可能影響 AWB（WB-11）。夜景含有人工燈與自然光時，可能要優先校正重要區域，或保留氣氛，沒有讓所有區域都中性的唯一設定（WB-12）。
