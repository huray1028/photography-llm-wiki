# 攝影新手教學 HTML 簡報

## 本機瀏覽

在專案根目錄啟動任一靜態 HTTP server，再開啟 `/presentation/`。直接雙擊 `index.html` 也能使用主要功能，但 HTTP server 更接近 GitHub Pages 環境。

## GitHub Pages

此專案根目錄含 `index.html`，會導向 `presentation/index.html`。將整個專案推送到 GitHub，並在 repository 的 Pages 設定選擇從主要分支根目錄發布即可。

## 操作

- 下一張：`→`、`PageDown` 或空白鍵
- 上一張：`←` 或 `PageUp`
- 第一張／最後一張：`Home`／`End`
- 目錄：`M`
- 全螢幕：`F`
- 離開目錄：`Esc`

## 素材

`assets/` 中的五張圖片由 OpenAI image generation 產生，專供本作業簡報使用。圖片沒有文字、品牌標誌或 Cambridge in Colour 原圖。
